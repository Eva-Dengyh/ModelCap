## 参数规矩（按任务）

### 任务：generate

| 参数 | 取值/约束 |
| --- | --- |
| 时长 | 4 ~ 12 秒 |
| 清晰度 | 720p、1080p |
| 画面比例 | 16:9、9:16、4:3、3:4、21:9、1:1 |
| 比例模式 | client_choice |
| 时长模式 | client_choice |
| 生成音频 | 支持 |

> 备注：时长口径各来源不一：生成器默认 4s、教程 5~8s、FAQ 5~12s（此处取 4~12s）；百炼 1.1 版为 3~15s。分辨率 1080p（另有 720p 标准档），FAQ 所称“原生 2K”未获核实。图生视频首帧图硬约束（格式/大小/边长）开源模型卡未给出；百炼 1.1 为 jpeg/jpg/png/webp ≤20MB、单边 ≥300px、比例 2:5~5:2。
